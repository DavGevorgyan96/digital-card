# Цифровая визитка

Статическая страница-визитка: человек сканирует QR-код, видит контакты, переходит в соцсети
или сохраняет контакт в телефон. Без базы данных, регистрации, сборки и платных сервисов.

Стек: обычные HTML + CSS + JavaScript. Зависимостей и шага сборки нет — папку можно
выложить на любой статический хостинг как есть.

```
digital-card/
├── index.html          страница
├── config.js           ← ВСЕ ДАННЫЕ ВИЗИТКИ (единственный файл для правки)
├── styles.css          оформление и раскладка
├── variants.css        варианты оформления: rose, aurora
├── assets/             фото, логотип, иконка сайта
├── js/
│   ├── app.js          отрисовка страницы, «Поделиться», QR-окно
│   ├── vcard.js        генерация файла контакта (vCard 3.0, UTF-8)
│   ├── qr.js           QR-код: матрица, SVG, проверка адреса
│   └── vendor/qrcode.js  генератор QR (qrcode-generator 1.4.4, MIT), лежит локально
└── tests/card.test.js  автотесты vCard и QR
```

## 1. Локальный запуск

Нужен любой простой веб-сервер (Python есть на macOS и Linux из коробки):

```bash
cd digital-card
python3 -m http.server 8080
```

Откройте <http://localhost:8080>. Чтобы посмотреть с телефона в той же Wi-Fi-сети,
откройте `http://IP-компьютера:8080` (копирование ссылки в буфер на таком адресе работает
через запасной способ, системное меню «Поделиться» — только по HTTPS).

Автотесты (нужен Node.js 18+, пакеты ставить не надо):

```bash
node --test tests/card.test.js
```

## 2. Как изменить данные

Откройте `config.js` — все поля подписаны комментариями.

- **Текст**: имя, должность, компания, описание — в блоке `person`.
- **Контакты**: `contacts` (телефон и WhatsApp — в международном формате с `+`,
  Telegram — имя пользователя без `@`).
- **Ссылки**: `links` — полные адреса профилей и сайта.
- **Адрес**: `address`. Ссылка на карту строится автоматически; точную ссылку можно
  указать в `mapUrl`.
- **Фото или логотип**: положите файл в `assets/` (квадратный, от 400×400 px, до ~200 КБ)
  и укажите путь: `photo: "assets/photo.jpg"`. Без фото показываются инициалы.
- **Вариант оформления**: `variant` — `"classic"` (тёмно-зелёная панель, антиква),
  `"rose"` (светлый, пудровые тона) или `"aurora"` (живой градиентный фон и анимация).
  Чтобы показать варианты, не меняя файл, откройте страницу с `?v=rose` или `?v=aurora`
  в адресе; пока `demo: true`, переключатель есть прямо на странице.
- **Свои цвета** (для `classic` и `rose`): блок `theme` (`accent` — фон панели с именем,
  `onAccent` — текст и кнопка на ней; отдельная пара для тёмной темы). Пусто = цвета варианта.
- **Страница без прокрутки**: визитка занимает ровно один экран на телефоне и компьютере.
  Поэтому длинное описание обрезается до 2–4 строк, а текст адреса виден списком только
  на большом экране компьютера (на телефоне адрес — кнопка, открывающая карту).
- Анимация отключается сама, если на устройстве включено «Уменьшение движения».
- **Подписи кнопок** (например, на армянском): блок `labels`, список ключей — в начале `js/app.js`.

Правила:

- Пустое значение `""` скрывает соответствующую кнопку или блок.
- Когда замените демо-данные, поставьте `demo: false` — исчезнет жёлтая плашка.
- После публикации впишите в `publicUrl` постоянный адрес страницы (см. раздел 4).

Заголовок вкладки формируется из `config.js`. Текст в предпросмотре ссылки в мессенджерах
берётся из тега `<meta name="description">` в `index.html` — при желании поправьте его вручную.

## 3. Публикация на бесплатном хостинге

Подойдёт любой статический хостинг. Два простых варианта:

### Вариант А — Cloudflare Pages (без Git, перетаскиванием)

1. Зарегистрируйтесь на <https://dash.cloudflare.com> (бесплатно).
2. Workers & Pages → Create → Pages → **Upload assets**.
3. Задайте имя проекта и перетащите папку `digital-card` целиком.
4. Получите адрес вида `https://имя-проекта.pages.dev`.
5. Обновление данных: поправьте `config.js` и загрузите папку снова (Create deployment).

### Вариант Б — GitHub Pages

1. Создайте публичный репозиторий на <https://github.com> и загрузите в него содержимое папки.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты страница доступна по адресу `https://логин.github.io/имя-репозитория/`.
4. Обновление данных: измените `config.js` в репозитории — сайт пересоберётся сам.

Аналогично работают Netlify (перетаскивание папки) и Vercel.

### Свой домен

В настройках хостинга (Custom domains) добавьте домен или поддомен, например
`card.ваш-домен.am`, и создайте у регистратора DNS-запись, которую покажет хостинг.
HTTPS-сертификат выпускается автоматически и бесплатно.

## 4. Финальный QR-код

1. Опубликуйте сайт и определитесь с **постоянным** адресом (лучше сразу свой домен).
2. Впишите его в `config.js`: `publicUrl: "https://card.ваш-домен.am/"` и опубликуйте заново.
3. Откройте визитку → **QR-код** → **Скачать SVG** (для типографии, вектор) или
   **Скачать PNG** (около 2400×2400 px).
4. Перед печатью тиража отсканируйте код телефоном с распечатанного образца.

Что важно знать:

- В QR-коде записан **сам адрес страницы** — без сервисов-посредников и перенаправлений.
  Код не «истекает» и ни от кого не зависит, пока работает адрес.
- **Данные можно менять сколько угодно** — QR-код остаётся прежним, пока не изменился адрес.
- **Если адрес или домен изменится, старый QR-код перестанет открывать визитку.**
  Тогда на старом адресе нужно настроить перенаправление (redirect) на новый — это возможно,
  только пока старый домен/хостинг остаётся под вашим контролем. Поэтому печатать код
  на адресе вида `*.pages.dev` или `*.github.io` стоит, только если вы уверены, что не будете
  его менять; надёжнее — свой домен.
- Пока в `publicUrl` демо-адрес, `localhost`, временный туннель или не-HTTPS, окно показывает
  только «образец», а скачивание заблокировано — чтобы в печать не ушёл нерабочий код.
- Рекомендации для печати: размер кода от 2×2 см (для визитки), белые поля вокруг не обрезать,
  не инвертировать цвета и не накладывать код на фото.

## 5. Расходы и ограничения

| Что | Стоимость |
| --- | --- |
| Код визитки, генерация QR, vCard | бесплатно, подписок нет |
| Хостинг (Cloudflare Pages, GitHub Pages, Netlify) | бесплатный тариф, для визитки достаточен |
| Адрес `*.pages.dev` / `*.github.io` | бесплатно, но это поддомен сервиса, а не ваш домен |
| Свой домен | **платно, ежегодно**: обычно порядка 10–20 $ в год за `.com`; домены `.am` заметно дороже — уточняйте у регистратора |

- **Бесплатного домена «навсегда» не бывает.** Бесплатный поддомен хостинга существует, пока
  существуют сервис, ваш аккаунт и их бесплатный тариф; условия могут измениться.
  Свой домен нужно продлевать каждый год — если не продлить, QR-код перестанет работать.
- Лимиты бесплатных тарифов (на момент написания; проверяйте актуальные условия на сайтах
  сервисов): GitHub Pages — публичный репозиторий на бесплатном аккаунте, мягкий лимит
  ~100 ГБ трафика в месяц; Cloudflare Pages — ограничение числа сборок в месяц, трафик
  не тарифицируется; Netlify — месячный лимит трафика. Визитка весит около 100 КБ,
  так что на практике в эти лимиты она не упирается.
- Статистики сканирований нет (нет отслеживания и перенаправлений). Формы обратной связи
  нет — для неё нужен сервер или сторонний сервис.
- Фото в файл контакта не добавляется (только текстовые поля).

## Что проверено

Проверено автоматически и в браузере на компьютере (Chromium, эмуляция экрана 360 и 390 px,
планшет 768 px, светлая и тёмная темы):

- автотесты: структура vCard 3.0, CRLF, экранирование `; , \` и переносов строк, армянский и
  русский текст, перенос длинных строк по 75 байт без разрыва символов, пропуск пустых полей;
- кнопка «Сохранить контакт» отдаёт файл `text/vcard; charset=utf-8` с ожидаемым содержимым;
- все ссылки (`tel:`, `mailto:`, `wa.me`, `t.me`, соцсети, карта) формируются корректно;
  пустые поля скрывают кнопки и блоки; HTML и `javascript:`-ссылки из конфига не исполняются;
- «Поделиться»: вызывается системное меню, если оно есть; иначе ссылка копируется и
  показывается уведомление (обе ветки проверены с подменой API браузера);
- QR: скачанный PNG (2368×2368 px, только чёрный и белый, поля 4 модуля) и SVG декодируются
  обратно ровно в адрес из `publicUrl` (проверено двумя независимыми декодерами);
  для демо/локального/не-HTTPS адреса скачивание заблокировано;
- страница помещается в один экран без прокрутки (замерено для всех трёх вариантов на
  360×620, 375×553, 390×700, 390×760, 768×1024, 1024×600, 1280×720, 1440×900);
  области нажатия не меньше 44 px (кроме переключателя вариантов в демо-плашке).

**Не проверено — нужен физический телефон:**

- iPhone (Safari): что по кнопке «Сохранить контакт» открывается карточка контакта с кнопкой
  добавления. На iOS файл открывается в той же вкладке, на остальных платформах — скачивается.
- Android (Chrome): что скачанный `.vcf` открывается приложением «Контакты» и армянский/русский
  текст отображается верно.
- Встроенные браузеры Instagram, Facebook, Telegram: в них скачивание файлов часто ограничено —
  возможно, пользователю придётся открыть страницу в Safari/Chrome.
- Реальное системное меню «Поделиться» на iOS и Android.
- Сканирование напечатанного QR-кода камерой телефона.
- Внешний вид фокуса с клавиатуры и работа со скринридером (VoiceOver/TalkBack) — стили и
  разметка заложены, вживую не проверялись.
